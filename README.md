This project builds a Recurrent Neural Network (RNN) model to classify IMDB movie reviews as positive or negative. The dataset consists of preprocessed movie reviews, where the most frequent 1,000 words are retained, and each review is padded to 100 words for uniformity. The model comprises an Embedding layer for word vectorization, a Simple RNN layer with 64 units for sequential learning, and a Dense output layer with a sigmoid activation function for binary classification. The model is trained using the Adam optimizer and binary cross-entropy loss for 50 epochs with a batch size of 64. After evaluation, the model predicts sentiment on test reviews, demonstrating real-world sentiment classification capability.
